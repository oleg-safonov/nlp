# NLP

Лемматизатор русского языка на Go.

Проект появился как попытка реализовать нативный лемматизатор, который по качеству сопоставим с `pymorphy3`, но при этом может использоваться непосредственно в Go-приложениях без внешних сервисов и Python-зависимостей.

В основе словаря используются данные OpenCorpora.

На текущий момент на корпусе **Universal Dependencies (ru_syntagrus-ud-test)** удалось получить следующие результаты:

| Решение | Точность | Скорость |
|----------|----------|----------|
| NLP | **96.17%** | **235 950 ток/сек** (без кеша) |
| pymorphy3 | 94.82% | 62 656 ток/сек* (с кешем, иначе в разы медленнее) |

Проект изначально проектировался с учетом особенностей Go runtime. При реализации хотелось избежать словаря, состоящего из большого количества связанных объектов и указателей, поэтому данные хранятся в компактных структурах с акцентом на локальность данных в памяти и снижение нагрузки на Garbage Collector.

## Почему было интересно это написать

Большинство известных инструментов для морфологического анализа русского языка написаны на Python. Для Go-проектов это часто означает отдельный сервис, вызовы через API или дополнительный слой интеграции.

Хотелось понять, насколько близко можно подойти к качеству существующих решений, используя только Go и данные OpenCorpora, и какие результаты можно получить, если проектировать словарь и алгоритмы с учетом особенностей рантайма.

## Пример использования

```go
package main

import (
    "fmt"
    "log"

    "github.com/oleg-safonov/nlp"
    nlprudata "github.com/oleg-safonov/nlp-ru-data"
)

func main() {
    base, err := nlprudata.Load()
    if err != nil {
        log.Fatal(err)
    }

    lem, err := nlp.NewLemmatizer(base)
    if err != nil {
        log.Fatal(err)
    }

    fmt.Println(lem.LemmatizeText("Съешь ещё этих мягких французских булок да выпей чаю"))
}
```

Результат (массив слов):

```
[съесть еще этот мягкий французский булка да выпить чай]
```
